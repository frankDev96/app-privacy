# PlaystackInteractive

App pages and privacy policies for HydroFit and Help Escape Arrow.

- [HydroFit](http://localhost:3000/hydrofit/) · [Privacy](http://localhost:3000/hydrofit/privacy)
- [Help Escape Arrow](http://localhost:3000/helpescapearrow/) · [Privacy](http://localhost:3000/helpescapearrow/privacy)

```bash
npm install
npm run dev
```

Add another app by registering it in `content/apps.ts` and adding its policy in `content/policies.tsx`.
