# App Privacy

Static privacy policies for apps published from this account.

- [HydroFit.do](http://localhost:3000/hydrofit/privacy)
- [Help Escape Arrow](http://localhost:3000/helpescapearrow/privacy)

```bash
npm install
npm run dev
```

Add another app by registering it in `content/apps.ts` and adding its policy in `content/policies.tsx`.
